# Audit Process

This directory stores governance and conformance audit records.

## Audit Types

- policy conformance audits,
- release process audits,
- security process audits,
- compatibility evidence audits.

## Required Audit Record Fields

Each audit record MUST include:
- audit scope,
- period covered,
- evaluator identity or role,
- findings with severity,
- required remediation actions,
- remediation owner,
- closure criteria and verification evidence.

## Remediation Tracking

Open findings MUST remain tracked until closure evidence is documented.
