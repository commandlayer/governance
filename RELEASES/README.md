# Release Coordination Records

This directory stores release coordination records for stack-level or governance-level release events.

## Record Requirements

Each record MUST include:
- release event identifier,
- release class,
- impacted repositories,
- sequencing confirmation,
- compatibility matrix reference,
- security assessment,
- sign-off identities or roles,
- rollback plan reference,
- final status.

## Authority

Release completion claims are valid only when documented in this directory.
